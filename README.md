# 公文写作工作区

在本目录打开 Agent，直接交办。首次使用无需填写全部档案。

## 从文件夹开始
“请从 D:\\材料 初始化工作区，先梳理我们单位、上级部门和合作方的关系。”

Agent 先登记材料，再重点阅读；会报告已读、未读及无法读取的范围。外部原文件保留原位，也可以自行把材料放入 `材料/原始材料/`。移动外部文件后告知 Agent 更新路径。来源变化会形成新版本，不抹去旧依据。

## 日常交办
- “参考这批材料，起草报送上级部门的合作情况汇报，突出阶段成果和协调事项。”
- “补充这份会议纪要，更新交付要求；还没有达成一致的部分不要当成承诺。”
- “继续上次汇报，篇幅压缩到两页，保留主要数据。”
- “我确认草稿第 2 版正文，请按单位模板输出 Word。”

正文通常先在 `写作任务/` 下以 Markdown 修改。工作依据、疑点与对外正文分开保存。确认后生成 Word 并检查版面；正文再发生实质变化时重新确认。

## 自动化范围
知识整理在执行任务时发生，不会后台监控文件夹。推断和冲突进入待确认清单。初步知识不代表全部材料已经读完。

五个技能在 `.agents/skills/`，子代理约定在 `agents/`。宿主若未自动发现技能，告诉 Agent 阅读 `AGENTS.md` 并按路径执行即可；子代理工具不可用时使用顺序工作流。Word、OCR 等能力依赖当前环境已有工具，缺失会明确报告。

首次填写核心单位、称谓与偏好，后续提供单位样稿或 Word 模板。真实材料和客户信息应保留在你授权的环境中，不自动发布或上传。
