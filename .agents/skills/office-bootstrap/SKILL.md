# 材料初始化

从工作区根目录执行，先读 AGENTS.md。用户未提供材料位置时检查 `材料/原始材料/`；没有材料再询问位置，不创建虚构业务数据。

1. 递归盘点授权目录中的 Word、Excel、PowerPoint、PDF、图片及文本，排除临时锁文件和工作区生成的提取内容、任务输出。不得跟随链接无限递归。外部原文件只登记不移动；写入只发生在工作区。
2. 读取 `材料/材料索引.md`，为新材料分配编号。比较指纹或可用文件元数据；内容变化新增版本，保留旧提取与历史依据；旧材料失联时记录失联，不删除知识。重复内容登记路径别名。
3. 先根据名称与目录筛选组织职责、近期合作和定稿公文，再读取原文确认。使用当前环境已有的对应文档技能或工具；扫描件需要 OCR，不可用则登记失败及原因。表格保留单位、表头和单元格定位，幻灯片保留页号，图片保留区域定位。
4. 提取内容按 `材料/提取内容/M0001-v1-标题.md` 保存，注明原始路径、版本、提取方法、实际范围、页码映射或替代定位和不确定识别位置。局部阅读不能标为整份已读。完成一批即更新索引，允许续接。
5. 调用 office-knowledge 整理有依据的初步知识。文件较多且可分割时按 `agents/材料阅读.md` 委派互不重叠的阅读范围，主 Agent 统一合并。
6. 更新 `工作区/工作状态.md`：盘点数量、已读/部分读取/未读/失败数量、核心组织候选、待确认事项、下一批阅读优先级。向用户说明覆盖边界，不宣称已全面掌握。

不以材料日期新就自动推翻旧事实；具体有效期和来源适用范围交由知识整理核对。
