# 组织知识整理
先读 AGENTS.md、知识索引及相关档案，采用 `模板/写作模板/知识档案.md`。查询任务只读。
1. 根据正式名称、别名与上下文匹配实体；同名部门不自动合并。沿用稳定编号，跨档案通过编号及相对路径引用。
2. 按独立事实记录来源版本、定位、适用时间与状态。区分隶属、指导、协作和合同关系；合作不能推导为隶属。
3. 合作事项记录方向、参与方、牵头及配合职责、阶段；交付要求记录谁向谁、交付物、时间、形式及验收要求，未知写“未明确”。
4. 有明确来源支持为“来源记载”；仅用户明确确认事实或纠正才为“用户确认”，记录日期和可见确认原意。正文定稿指令不提升长期知识状态。
5. 推断、冲突和拟新增的重要承诺进入待确认清单；相关档案引用问题编号，保留冲突双方依据，解决前不能作为无条件结论。
6. 同来源版本同一事实不重复新增；新证据补充原条目。依据有效期与适用范围判断替代，不仅看文件日期；保留变更历史。草稿建议、目标、预测不记成已发生事实。
7. 主 Agent 统一合并和写入档案、索引与待确认清单，更新受影响任务。一次任务的要求不扩展成通用口径。报告新增、修订及待确认项。
