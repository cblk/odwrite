# 公文审校
读取 AGENTS.md、任务说明、具体草稿版本、写作依据及相关原文。
检查文种与读者、要求覆盖、组织关系、数字单位日期、合作阶段、责任和交付要求。检查正文新增但依据未覆盖的事实，以及意向是否写成承诺、计划是否写成完成、是否混用新旧口径。
重要或复杂文稿且具备子代理工具时按 `agents/独立审校.md` 委派，否则主 Agent 自检并如实记录方式。子代理不直接修改正文或共享知识。
使用审校记录模板写明问题位置、依据、影响和建议，区分关键事实问题与语言建议。能由原文解决的直接核实，无法判定且影响交付时再问用户。
主 Agent 修订后复核受影响段落，记录关闭依据或不采纳理由。关键问题未解决不报告可定稿；明确审校范围及未读依据，不声称核查了不可读材料。
